============================================================
 SHIELDTECH — IMAGE PLACEMENT GUIDE
============================================================
How to add your own photos so ALL visitors see them.

------------------------------------------------------------
 QUICK START (3 steps)
------------------------------------------------------------
1. Open this folder:   img/
2. Prepare your photo as a .jpg (or .png for the logo).
3. Drop it into the matching subfolder with the EXACT file
   name listed below (overwrite the placeholder).

You're done — no code changes needed. When you upload the
img/ folder to your host (via file manager or FTP), the new
photos appear on the live site for everyone.

------------------------------------------------------------
 IMPORTANT RULES
------------------------------------------------------------
- Keep the exact filename (e.g. hero-1.jpg must stay hero-1.jpg).
- Use .jpg for photos, .png only for the logo.
- Keep files small (under ~500KB each) so the site loads fast.
- Landscape photos work best for banners and cards.
- The Admin page's "Preview Override" only affects your own
  browser — a placeholder for testing, NOT a permanent change.
  Permanent = replace the file in this folder.
